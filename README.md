# Minimalist Dark Tab Extension

A sleek, dark-themed Chrome extension that replaces your "New Tab" page with a minimalist dashboard.

## Features
- **Minimalist Design**: Dark gradient background with a grain overlay.
- **Search Bar**: Quick Google search integration.
- **Live Clock**: Discrete time and date display.
- **Top Sites**: Automatically fetch and display your most visited websites.
- **Quick Access**: Functional buttons for Chrome History and Bookmarks.

## Development

```bash
# Install dependencies
npm install

# Run development server
npm run dev
```

## How to Install as an Extension

1.  **Build the project**:
    ```bash
    npm run build
    ```
2.  **Open Chrome Extensions**:
    Navigate to `chrome://extensions/` in your browser.
3.  **Enable Developer Mode**:
    Toggle the "Developer mode" switch in the top right.
4.  **Load Unpacked**:
    Click "Load unpacked" and select the `dist` folder in this project directory.
